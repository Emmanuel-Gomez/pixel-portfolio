# Emmanuel Gomez — Pixel Portfolio

Static website built with HTML, CSS and vanilla JavaScript. No installation or build step is required.

## Run locally
Extract this archive and open index.html in your browser, or use VS Code Live Server.
You can also run `python -m http.server 8000` from this folder and visit http://localhost:8000.

## Files
- index.html: page structure
- style.css: styling, responsive layout and sprite positioning
- app.js: career content, English/Swedish translations, scrolling and animation
- assets/: city panoramas and avatar sprite sheets (including earlier image versions)

## Edit content
In app.js, edit the chapters array for your experience, environments for backgrounds,
and contact for your email and LinkedIn URL.

## Hosting
Upload index.html, style.css, app.js and assets/ to any static web host.
Keep their relative paths intact. No backend, framework, API keys or credentials are required.
